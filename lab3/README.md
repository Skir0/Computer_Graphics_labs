# Лабораторная работа 3. Базовые растровые алгоритмы

## Цель работы

Реализовать и сравнить алгоритмы построения отрезков и окружностей на дискретной сетке: пошаговый алгоритм, ЦДА, Брезенхем для отрезка, Брезенхем для окружности. Дополнительно реализованы алгоритм Кастла–Питвея и сглаживание отрезка по Ву.

## Описание алгоритмов

Пошаговый алгоритм использует уравнение прямой `y = kx + b`. Для каждого значения главной координаты вычисляется вторая координата, после чего результат округляется до ближайшего пикселя. Метод прост для понимания, но требует дробных вычислений.

Алгоритм ЦДА строит отрезок равными шагами. Число шагов равно большей разности координат: `L = max(|dx|, |dy|)`. На каждом шаге к текущим координатам прибавляются `dx / L` и `dy / L`, а полученная точка округляется. Метод также работает с дробными числами.

Алгоритм Брезенхема для отрезка использует решающую функцию и целочисленную арифметику. По знаку функции выбирается следующий пиксель: прямо по главной оси или по диагонали. Благодаря этому алгоритм работает быстро и не использует операции с плавающей точкой.

Алгоритм Брезенхема для окружности сначала строит одну восьмую окружности. Остальные точки получаются симметричным отражением относительно осей и диагоналей. Выбор следующей точки выполняется по целочисленной решающей функции.

Алгоритм Кастла–Питвея представляет отрезок последовательностью двух типов шагов: прямого и диагонального. Количество этих шагов определяется разностями координат, а их равномерное чередование строится с помощью алгоритма Евклида. В отличие от Брезенхема, в процессе рисования не вычисляется ошибка — используется заранее построенная последовательность шагов.

Сглаживание по Ву для каждого шага выбирает два соседних пикселя. Их яркости зависят от расстояния до идеальной линии: ближайший пиксель получает большую яркость, второй — меньшую. Поэтому линия выглядит менее ступенчатой, чем при обычной растеризации.

## Привязка координат к дискретной сетке

Пиксель с целочисленными координатами `(x, y)` считается клеткой размером 1×1, центр которой находится в точке `(x, y)`. Границы клеток проходят по полуцелым координатам: `... -0,5; 0,5; 1,5 ...`. Оси проходят через центры клеток `x = 0` и `y = 0`, а подписи размещаются около центров клеток. На экране ось `y` направлена вверх, поэтому при выводе экранная координата по вертикали инвертируется. Идеальная линия показывается красным цветом, а выбранные растровые пиксели выделяются оранжевой рамкой.

## Пример вычислений

Рассмотрим отрезок от `(1, 1)` до `(12, 6)`. Для него `dx = 11`, `dy = 5`.

В пошаговом алгоритме наклон равен `k = 5 / 11 ≈ 0,4545`. При переходе к следующему значению `x` значение `y` увеличивается примерно на 0,4545 и округляется. Получается 12 пикселей, начиная с `(1, 1)` и заканчивая `(12, 6)`.

В ЦДА используются приращения `sx = 1` и `sy = 5 / 11 ≈ 0,4545`. Координаты увеличиваются на эти значения, после чего округляются.

В алгоритме Брезенхема начальное значение решающей функции равно `d = 2dy - dx = -1`. По знаку `d` выбирается прямой или диагональный шаг. В результате также получается 12 пикселей.

Для окружности радиуса 8 начальное значение функции равно `d = 3 - 2R = -13`. После построения точек одной восьмой части они отражаются и образуют всю окружность.

Для Кастла–Питвея в этом примере нужно выполнить 6 прямых и 5 диагональных шагов. Алгоритм Евклида расставляет их в последовательность `sdsdsdsdsds`, где `s` — прямой шаг, а `d` — диагональный.

При сглаживании по Ву, например, если идеальная линия проходит между строками пикселей на расстоянии `0,45`, соседние пиксели получают яркости примерно `0,55` и `0,45`. Суммарная яркость сохраняется равной единице.

## Временные характеристики

Время измеряется непосредственно в приложении многократным запуском алгоритма без построения таблицы и без отрисовки. Для примера `(1, 1) — (12, 6)` типичные результаты составляют: пошаговый алгоритм — около 2,1 мкс, ЦДА — 2,6 мкс, Брезенхем для отрезка — 1,4 мкс, Брезенхем для окружности радиуса 8 — 6,2 мкс. Для Кастла–Питвея и Ву время также следует смотреть кнопкой «Замер времени», так как оно зависит от компьютера.

На большом отрезке `(0, 0) — (1000, 600)` ранее получены значения около 135 мкс для пошагового алгоритма, 171 мкс для ЦДА и 105,7 мкс для Брезенхема. Окружность радиуса 500 строится примерно за 679,4 мкс. Эти числа являются ориентировочными.

## Вывод

Пошаговый алгоритм и ЦДА проще объяснить, но они используют дробные вычисления. Брезенхем для отрезка обычно быстрее, поскольку работает с целыми числами. Брезенхем для окружности использует симметрию, что уменьшает число расчётов. Кастл–Питвей строит линию по заранее полученной последовательности шагов, а алгоритм Ву повышает визуальное качество линии за счёт изменения яркости соседних пикселей.
