# Лабораторная работа 2 (вариант 10)

Реализовано:
- **Нелинейный фильтр на порядковых статистиках** - медианный (окно 3x3 ... 9x9, для цветных изображений по каналам).
- **Глобальная пороговая обработка**, два метода: **Оцу** и **итерационный (Ридлер-Калвард)**.

## Запуск
```
pip install -r requirements.txt
python main.py
```
Для получения `lab2.exe` запустите на Windows `build_exe.bat` (результат: `dist\lab2.exe`).

## Файлы
- `main.py` - графический интерфейс (tkinter)
- `filters.py` - медианный фильтр
- `threshold.py` - перевод в градации серого, гистограмма, методы Оцу и итерационный

## Работа с приложением
1. «Открыть изображение» (любой файл или из папки `test_images`).
2. «Медианный фильтр» - результат справа от исходного.
3. «Глобальный порог» - рядом показываются результаты Оцу и итерационного метода с найденными порогами.
4. «Результат фильтра -> исходное» - чтобы применить порог к изображению, очищенному от шума.

Под каждой панелью выводится гистограмма яркости (в логарифмическом масштабе, чтобы пики шума «соль и перец» не скрывали остальное):
- под исходным изображением - гистограмма исходника;
- под результатом медианы - гистограмма отфильтрованного изображения (видно, как исчезают пики на 0 и 255);
- под результатами Оцу и итерационного метода - гистограмма исходника с красной линией найденного порога T.

Изображения больше 1000 пикселей по большей стороне при открытии уменьшаются (чтобы медиана работала быстро).

## Пояснения
**Медианный фильтр.** Для каждого пикселя значения окна сортируются, берется средний элемент. Выбросы (белые/черные точки) оказываются на краях отсортированного ряда и не влияют на результат, поэтому «соль и перец» подавляется лучше, чем усредняющим фильтром, а границы объектов не размываются. Чем больше окно, тем сильнее подавление шума, но тем больше теряются мелкие детали.

**Метод Оцу.** Перебираются все пороги t = 0..255, для каждого вычисляется межклассовая дисперсия `w0 * w1 * (mu0 - mu1)^2`; выбирается порог с максимумом. Метод находит глобальный максимум, поэтому хорошо работает на мелких объектах, но может «зацепиться» за небольшую группу очень ярких пикселей (блики).

**Итерационный метод.** Начальный порог - средняя яркость; на каждом шаге считаются средние яркости пикселей ниже и выше порога, новый порог - их полусумма; повторяется до изменения меньше 0,5. Метод находит локальное решение, зависящее от начального приближения: устойчив к бликам, но на изображениях с малым объектом средняя яркость почти равна яркости фона, и порог оказывается внутри шума фона.
